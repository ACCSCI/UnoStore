# v0.1.6 窥镜观察模式

- “隐藏窥镜”现在会收起整个窥镜决策界面与遮罩，只在右下角保留“显示窥镜”按钮，方便完整观察场上局势后再决策。
- 暂时收起窥镜不会丢失已选择的“拿走/弃掉”卡牌，单机与联机使用相同交互。

# v0.1.5 账号与联机席位简化

- 移除首页账号头像与旧多人入口中的远端头像，只保留稳定可读的 VibeHub 用户名和 ID。
- 移除联机圆桌席位头像，席位继续显示玩家名、ID、UNO/炉石数量、水晶与严格对应手牌数量的牌背。
- 调整无头像席位为双列文字布局，目标高亮、键盘焦点与目标选择的无障碍名称保持不变。

# v0.1.4 联机席位与 UNO 判定修复

- 修复两名真人偶尔显示成三人的问题：VibeHub Beta SDK 的 `peers()` 同时包含玩家与 VibeNet relay 路径；现在只按真实玩家 peer ID 去重计数，主中继、暖备和候选节点不再占用席位。
- 联机战场改为与 2–8 人单机混战相同的圆桌 UI：玩家沿桌边均匀分布，显示英雄、VibeHub ID、UNO/炉石数量、水晶、严格对应数量的牌背，以及当前与下一位高亮。
- 修复彩色“全员跳过”打出后丢失当前颜色、导致同色牌无法继续打出的联机权威判定错误。
- “同色清场”增强：弃掉的所有数字牌会按点数求和，并转化为本回合的冻结水晶；被清掉的功能牌仍不会触发自身效果。
- 补充双人局“反转 +4”说明：跳过对手但由出牌者自己承受四张，可继续叠加不小于 +4 的罚抽牌把累计处罚送回对手。
- VibeHub 登录连接被浏览器 Local Network Access/CORS 拦截时，首屏会显示可操作的权限与扩展排查提示。

# v0.1.3 联机房间、存档与回合体验修复

- 联机房间显示 VibeHub 用户名与用户 ID；房主可自由添加、移除机器人，机器人会作为正式席位出牌、施法、攻击并参与胜负结算。
- 英雄语音改为独立的社交事件旁路播放，不再占用卡牌演出锁，也不会打断出牌、目标选择或结束回合按钮。
- 单机与联机回合统一加入最长 2 分钟倒计时；联机由房主权威结算超时，避免各客户端计时漂移。
- VibeHub 登录入口前置到首屏；未登录时存档只保存在本机，登录后可比较本地与云端修改时间，并选择本地、云端或手动合并。
- 修复剧情失败仍解锁下一章的问题，并自动修复旧版本产生的错误解锁记录。
- 牌库构筑改为显式“保存出战配置”，卡牌悬停或键盘聚焦会显示完整放大详情；单机人数改由首页选择。

# v0.1.2 联机演出与交互修复

- 联机对局改为串行消费房主权威事件：各客户端会在本地播放出牌、抽牌、施法、随从召唤、攻击、受击、英雄技能、语音与音效，演出完成前不会提前进入下一次操作。
- 补全颜色轮盘联机结算：下家显式选色、全场展示选色结果、逐张公开抽牌，结算后把控制权交还原出牌玩家。
- 修复联机打出数字 7 未选择目标的问题；现在会先选择仍在场的玩家，再交换双方全部 UNO 与炉石手牌。
- 补全联机炉石牌目标选择、己方手牌选择、随从攻击目标、英雄技能与随时可用的英雄语音入口。
- 修复房间人数原生下拉菜单在深色界面中显示为白底浅字的问题。
- 联机快照仅向窥镜效果的施放者发送公开手牌详情，保持其他玩家私有手牌不可见。
