# v0.1.9 双人联机身份修复

- 调整英雄技能：暴徒 2 费随机弃掉至多两张混合手牌并获得 1 层护盾；卡牌大师改为 1 费选择弃掉一张己方 UNO，再从所有在场玩家的出战牌池随机换取一张炉石牌。单机、AI 与房主权威联机使用相同规则。
- UNO 湮灭在手中不足 5 张 UNO 时不再要求逐张选择，直接弃掉现有全部 UNO；护盾层数改为显示在英雄头像左下角。
- 修复联机反转 +4 罚抽链卡死：行动次数耗尽后仍可叠加合规罚抽牌，无法叠加时可结束回合接受罚抽；即使牌面演出异常也会恢复操作并渲染最新房主快照。
- 修复客人身份消息早于座位建立时被永久丢弃的问题；房主现在会缓存早到身份，客人在连接、分配座位和重连后都会重新同步身份。
- 修复客人退出再进后旧连接残留、两名玩家显示成三人的问题；大厅只统计已打开、非重连且未离开的真人连接。

- 修复 PC 拿起手牌后只能在手牌附近小范围移动的问题：卡牌现在会跨越整个视口持续跟随鼠标，包括牌桌、HUD 与屏幕四角；右键可在任意位置取消拿牌，并会阻止浏览器上下文菜单。

- 新增四张炉石法术：战阵轮转（按当前顺序传递全部随从）、单骑易位（两名英雄各交换一个随机随从）、军团易帜（两名英雄交换全部随从）、混沌点将（全场随从随机重分）；同步加入构筑、AI、立绘、动画主题和对局记录。
- 闪电箭、数字 7 与其他指定英雄/随从效果统一改成圆桌直接点选；两目标法术会同时高亮合法英雄，不再弹出玩家选择框。
- PC 单击卡牌后由卡牌本身跟随指针，再点击桌面才打出，不再保留红框锁定或额外点击预览；手机短按不选牌，长按拖到桌面释放才打出。
- PC 拿起手牌后可右键取消；双人局反转 +4 将罚抽转回自己时，仍可继续叠加另一张合规罚抽牌并把整条罚抽链传给对手。
- 清空最后一张罚抽牌或颜色轮盘时不再提前获胜：必须等待选色、公开抽牌和整条罚抽叠加链完全结算；若期间被反转 +4 传回并重新抽牌，候选胜利会自动撤销。
- 联机对齐单机多人圆桌：玩家 ID、准备状态、机器人、目标选择、对局记录、手牌牌背、结算界面、淘汰即时提示与自动跳过均使用同一套规则。
- 修复所有颜色“全员跳过”后的颜色延续、数字 7 交换、轮盘控制权、断线席位与重复人数等问题；演出期间显示 UNO/炉石手牌数量变化。
- 新增血尺裁决者 3 费 2/4；攻击时弃掉己方所有点数低于其当前生命值的 UNO 数字牌。
- 手机对局强制横屏并保持 PC 布局不变，禁止页面缩放、滚动和浏览器拖拽；游戏界面文字不再被误选中，房间号提供一键复制和成功反馈。
- 云存档网络失败会明确提示代理 Fake-IP/本地网络权限排查方式。
- 新增 4 费法术“众生平等”：将全场随从的攻击力、当前生命值与生命上限统一变为 1/1，同时保留随从原有效果。
